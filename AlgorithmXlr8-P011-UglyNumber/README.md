# Ugly Number

**Difficulty:** `Easy`

## Problem

An ugly number is a positive integer which does not have a prime factor other than 2, 3, and 5.

Given an integer n, return true if n is an ugly number.

By this definition 1 is an ugly number, because it has no prime factors at all. Zero and negative numbers are never ugly, because an ugly number must be positive. A number such as 14 = 2 x 7 is not ugly, because 7 is a prime factor other than 2, 3 and 5.

Input format: a single line containing the integer n.

Output format: print true if n is an ugly number, otherwise print false.

## Examples

### Example 1

**Input**
```
n = 6
```
**Output**
```
true
```

**Explanation:** 6 = 2 x 3, and both prime factors are allowed.

### Example 2

**Input**
```
n = 1
```
**Output**
```
true
```

**Explanation:** 1 has no prime factors, therefore all of its prime factors are limited to 2, 3, and 5.

### Example 3

**Input**
```
n = 14
```
**Output**
```
false
```

**Explanation:** 14 is not ugly since it includes the prime factor 7.
