# Add Two Integers

**Difficulty:** `Easy`

## Problem

Given two integers num1 and num2, return the sum of the two integers.

Either number may be negative, zero or positive, and the result may be negative too. There is no trick: the whole task is a single addition. It is a good warm up for checking how your language reads two integers from standard input and prints a result.

- num1 and num2 are each between -100 and 100 inclusive.
- So the sum is always between -200 and 200 and fits easily in any integer type.

Input format: a single line with two integers num1 and num2 separated by a space.

Output format: print a single integer, the value of num1 + num2.

## Examples

### Example 1

**Input**
```
num1 = 12, num2 = 5
```
**Output**
```
17
```

**Explanation:** num1 is 12, num2 is 5, and their sum is 12 + 5 = 17, so 17 is returned.

### Example 2

**Input**
```
num1 = -10, num2 = 4
```
**Output**
```
-6
```

**Explanation:** num1 + num2 = -10 + 4 = -6.

### Example 3

**Input**
```
num1 = -100, num2 = -100
```
**Output**
```
-200
```

**Explanation:** Both numbers are at the lower limit, and -100 + (-100) = -200.
